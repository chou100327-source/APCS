# 01 輸入與輸出

APCS 實作題一定要處理輸入輸出，**格式錯了整題會判 0 分**，所以這裡務必練熟。

---

## 讀輸入的四種基本寫法

```python
# 讀入一行文字（永遠是字串）
name = input()
print("Hello,", name)

# 讀入整數 / 浮點數：input() 之後要自己轉型
n = int(input())
x = float(input())

# 一行有多個數字，用空白隔開
# 例如輸入： 3 5 7
a, b, c = map(int, input().split())
print(a + b + c)   # 15

# 如果不知道有幾個數字，全部丟進 list
nums = list(map(int, input().split()))
print(sum(nums))
```

重點：`input()` 拿到的**永遠是字串**，要算數學一定得先 `int()` 或 `float()` 轉型。

---

## print() 的常用參數

```python
print("A", "B", "C")                 # A B C   （預設用空白分隔）
print("A", "B", sep="-")             # A-B     （改分隔符號）
print("no newline", end="")          # 不換行
print(1, 2, 3, sep=", ", end="!\n")  # 1, 2, 3!
```

---

## 格式化字串（f-string）

APCS 允許 Python 3，f-string 很好用：

```python
score = 87.5
name = "小明"
print(f"{name} 的分數是 {score}")
print(f"{score:.1f}")      # 87.5   （取到小數第 1 位）
print(f"{score:6.2f}")     # " 87.50"（總寬度 6，含 2 位小數）
print(f"{42:03d}")         # 042    （補零到 3 位數）
```

---

## 考場小技巧：不知道有幾筆資料

如果題目沒說輸入資料有幾筆，常見寫法是用 `while True` 搭配 `try / except` 抓 `EOFError`，直到讀不到資料為止；或者第一行先給你一個 N 代表接下來有幾筆資料。

```python
import sys

for line in sys.stdin:
    line = line.strip()
    if line == "":
        continue
    print("讀到：", line)
```

## 五分鐘小練習

```quiz
Q: `input()` 讀進來的資料型態永遠是什麼？
* 字串 str
- 整數 int
- 依內容自動判斷
- 浮點數 float
E: input() 一律回傳字串，要做數學運算前必須自己用 int() 或 float() 轉型。

Q: 輸入一行是 `3 5 7`，想一次拿到三個整數，下列何者正確？
* `a, b, c = map(int, input().split())`
- `a, b, c = input()`
- `a, b, c = int(input())`
- `a, b, c = input().split(int)`
E: 先 .split() 依空白切成三個字串，再用 map(int, ...) 把每個都轉成整數，最後同時指派給三個變數。

Q: `print(f"{3.14159:.2f}")` 會輸出什麼？
* 3.14
- 3.142
- 3.14159
- 3
E: `:.2f` 代表取到小數第 2 位（會四捨五入）。`:03d` 則是補零到 3 位整數。
```

## 常見錯誤

- **忘記轉型**：`n = input()` 之後直接 `n + 1` 會噴 `TypeError`，字串不能跟整數相加。
- **多印提示文字**：`print("請輸入 N：")` 這種提示在 APCS 會被當成輸出的一部分而判錯，**只印答案本身**。
- **輸出格式沒對齊題目**：該換行沒換行、多一個空白、小數位數不對，都會 WA。送出前一定要拿範例輸入跑一遍，逐字比對範例輸出。
- **`.split()` 忘了加**：`map(int, input())` 會把整行字串的每個字元都拿去轉，不是你要的結果。
