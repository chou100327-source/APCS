# 02 資料型態與變數

Python 的變數**不用宣告型別**，指派值的當下型別就決定了。APCS 觀念題常考「猜型別」「猜輸出」，所以要很熟悉基本型態彼此轉換的規則。

---

## 五個基本型態

| 型態 | 說明 | 範例 |
|---|---|---|
| `int` | 整數，Python 的整數沒有大小限制 | `x = 10` |
| `float` | 浮點數（小數） | `y = 3.14` |
| `str` | 字串，用單引號或雙引號 | `s = "APCS"` |
| `bool` | 布林值，只有 `True` / `False` | `flag = True` |
| `list` | 串列（可變、可放不同型態） | `a = [1, 2, 3]` |

```python
a = 7          # int
b = 7.0        # float
c = "7"        # str
print(type(a), type(b), type(c))
# <class 'int'> <class 'float'> <class 'str'>
```

---

## 型別轉換

```python
n = int("123")     # 字串轉整數 -> 123
f = float("3.5")   # 字串轉浮點數 -> 3.5
s = str(456)       # 數字轉字串 -> "456"

print(int(7.9))    # 無條件捨去小數 -> 7（不是四捨五入！）
print(int(-7.9))   # -> -7（往 0 的方向捨去）
```

> **常見陷阱**：`int()` 對浮點數是「無條件捨去（truncate）」，不是四捨五入；`int("3.5")` 會直接噴錯，因為字串裡有小數點，必須先轉成 `float` 再轉 `int`。

---

## 變數命名與多重指派

```python
x, y = 1, 2
x, y = y, x        # 交換變數值，不需要暫存變數
print(x, y)        # 2 1

PI = 3.14159       # 全大寫通常代表「這是常數」（Python 沒有強制唯讀）
```

## 五分鐘小練習

```quiz
Q: `print(int(-3.7))` 會輸出什麼？
* -3
- -4
- 3
- 4
E: int() 是往 0 的方向捨去（truncate），所以 -3.7 變成 -3。要往下取整要用 math.floor()，那才會得到 -4。

Q: 下列哪一行會直接噴錯？
* `int("3.5")`
- `float("3.5")`
- `int(3.5)`
- `str(3.5)`
E: int() 不接受帶小數點的字串，必須先 float("3.5") 轉成 3.5 再 int() 變成 3。

Q: `x, y = 1, 2` 之後執行 `x, y = y, x`，x 與 y 分別是？
* x=2, y=1
- x=1, y=2
- x=2, y=2
- 會噴錯
E: Python 右邊會先整包算好 (2, 1) 再一次指派回左邊，所以能直接交換，不需要暫存變數。
```

## 常見錯誤

- **把 `int()` 當四捨五入用**：要四捨五入請用 `round()`，但 `round()` 有「銀行家捨入」的坑（見單元 03）。
- **字串數字直接相加**：`"3" + "4"` 得到 `"34"` 不是 `7`，這是觀念題很愛考的誘答。
- **用 `list` 或 `str` 當變數名**：`list = [1,2,3]` 之後就不能再用 `list()` 這個內建函式了，取名要避開內建名稱。
