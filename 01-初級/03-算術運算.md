# 03 算術運算

算術運算是初級題本的核心考點。APCS 觀念題最常見的形式是**給一段運算式問你結果**，或**給一小段程式問最後變數的值**。這裡的每個細節都可能是陷阱。

---

## 七個算術運算子

| 運算子 | 意義 | 範例（a=7, b=2） | 結果 |
|---|---|---|---|
| `+` | 加 | `a + b` | 9 |
| `-` | 減 | `a - b` | 5 |
| `*` | 乘 | `a * b` | 14 |
| `/` | 除（結果一定是小數） | `a / b` | 3.5 |
| `//` | 整數除法 | `a // b` | 3 |
| `%` | 取餘數 | `a % b` | 1 |
| `**` | 次方 | `a ** b` | 49 |

```python
print(7 / 2)    # 3.5  ← 就算整除也會是小數
print(6 / 2)    # 3.0  ← 注意是 3.0 不是 3
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 10)  # 1024
```

---

## 最常考的陷阱：負數的 `//` 與 `%`

Python 的整數除法是**往負無窮方向捨去**，餘數的正負號**跟除數相同**，這跟 C、Java 的行為不一樣，考卷上很愛拿這個當誘答。

```python
print(-7 // 2)   # -4   （不是 -3！-3.5 往下捨去是 -4）
print(-7 % 2)    #  1   （因為 -7 = (-4)×2 + 1）
print(7 // -2)   # -4
print(7 % -2)    # -1   （除數是負的，餘數也是負的）
```

## 運算子優先順序

由高到低，同一層由左往右算（`**` 例外，是**由右往左**）：

```
()          括號
**          次方
+x  -x      正負號
*  /  // %  乘、除、整除、取餘
+  -        加、減
```

```python
print(2 + 3 * 4)        # 14   先乘後加
print((2 + 3) * 4)      # 20   括號改變順序
print(2 + 3 * 4 ** 2)   # 50   4**2=16 → 3*16=48 → 2+48=50
print(2 ** 3 ** 2)      # 512  由右往左：3**2=9 → 2**9=512（不是 64！）
print(10 - 4 - 3)       # 3    由左往右：(10-4)-3
```

## 複合指定運算子

```python
x = 10
x += 3    # 等同 x = x + 3  → 13
x -= 5    # → 8
x *= 2    # → 16
x //= 3   # → 5
x %= 3    # → 2
x **= 4   # → 16
print(x)
```

## 常用的數學相關內建函式

```python
print(abs(-7))          # 7      絕對值
print(round(3.456, 2))  # 3.46   四捨五入到小數第 2 位
print(max(3, 9, 5))     # 9
print(min(3, 9, 5))     # 3
print(divmod(17, 5))    # (3, 2) 同時取商和餘數

import math
print(math.sqrt(16))    # 4.0
print(math.floor(3.7))  # 3   往下取整
print(math.ceil(3.2))   # 4   往上取整
```

> **`round()` 的銀行家捨入**：Python 的 `round()` 遇到正好 `.5` 時會捨入到**最接近的偶數**，所以 `round(0.5)` 是 `0`、`round(1.5)` 是 `2`、`round(2.5)` 也是 `2`。要一般的四捨五入，用 `int(x + 0.5)`（限正數）比較保險。

## 典型考題：拆解數字的每一位

```python
# 把三位數 n 的百位、十位、個位拆出來
n = 472
hundreds = n // 100        # 4
tens = (n // 10) % 10      # 7
ones = n % 10              # 2
print(hundreds, tens, ones)

# 求各位數字總和（任意位數）
n = 9384
total = 0
while n > 0:
    total += n % 10   # 取出最右邊一位
    n //= 10          # 去掉最右邊一位
print(total)   # 24
```

## 五分鐘小練習

```quiz
Q: `print(-7 // 2)` 會輸出什麼？
* -4
- -3
- 3
- 4
E: Python 的 // 是往負無窮方向捨去，-3.5 往下捨去就是 -4。這跟 C/Java 的「往 0 捨去」不同，是最常考的誘答。

Q: `print(2 ** 3 ** 2)` 會輸出什麼？
* 512
- 64
- 36
- 12
E: ** 是右結合（由右往左算），所以先算 3**2=9，再算 2**9=512。若是左結合才會是 (2**3)**2=64。

Q: `print(6 / 2)` 的輸出是？
* 3.0
- 3
- 2
- 3.5
E: 在 Python 3 裡 / 一律回傳浮點數，就算整除也會印出 3.0。要得到整數 3 要用 6 // 2。

Q: 想取出整數 n 的「十位數」，下列何者正確？
* `(n // 10) % 10`
- `n % 10`
- `n // 10`
- `n % 100`
E: 先 //10 把個位砍掉，再 %10 取出最右邊那位（原本的十位）。n % 10 拿到的是個位數。
```

## 常見錯誤

- **忘了 `/` 一定回傳小數**：要索引陣列、要當迴圈次數的時候用 `/` 會噴 `TypeError`，該用 `//`。
- **負數取餘數想成 C 的行為**：Python 的 `-7 % 2` 是 `1`，不是 `-1`。實際上這個特性在凱撒加解密裡很好用（見單元 10）。
- **`**` 的結合方向記反**：`2 ** 3 ** 2` 是 512 不是 64。
- **`round()` 當成一般四捨五入**：`round(2.5)` 是 2，不是 3。
