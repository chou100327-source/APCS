# 04 邏輯運算

邏輯運算處理的是「真」與「假」。初級題本常把邏輯運算和條件判斷綁在一起考，重點在於**能正確判斷一個複合條件的真假值**。

---

## 布林值與比較運算子

比較運算的結果一定是布林值 `True` 或 `False`（注意首字母大寫）。

| 運算子 | 意義 | 範例 | 結果 |
|---|---|---|---|
| `==` | 等於 | `3 == 3` | `True` |
| `!=` | 不等於 | `3 != 5` | `True` |
| `>` | 大於 | `3 > 5` | `False` |
| `<` | 小於 | `3 < 5` | `True` |
| `>=` | 大於等於 | `5 >= 5` | `True` |
| `<=` | 小於等於 | `5 <= 3` | `False` |

> 別把 `=` 和 `==` 搞混。`=` 是**指定**（把值存進變數），`==` 才是**比較**。這是除錯題最愛的錯誤來源。

---

## 三個邏輯運算子

```python
print(True and False)   # False  兩個都真才真
print(True or False)    # True   有一個真就真
print(not True)         # False  反轉真假
```

### 真值表（一定要背熟）

| A | B | A and B | A or B | not A |
|---|---|---|---|---|
| True | True | True | True | False |
| True | False | False | True | False |
| False | True | False | True | True |
| False | False | False | False | True |

---

## 優先順序：`not` > `and` > `or`

```python
print(True or False and False)
# and 先算：False and False = False
# 再算 or：True or False = True  → True

print((True or False) and False)
# 加括號改變順序 → False
```

---

## 短路求值（考過很多次）

`and` 只要左邊是假就直接回傳假，右邊根本不會執行；`or` 只要左邊是真就直接回傳真。這個特性常被拿來避免錯誤。

```python
x = 0
if x != 0 and 10 / x > 1:   # 左邊已是 False，右邊不會算，不會除以零
    print("yes")
else:
    print("no")   # 輸出 no，程式不會當掉

# 如果把順序寫反就會出錯：
# if 10 / x > 1 and x != 0:   ← ZeroDivisionError
```

---

## 笛摩根定律

```
not (A and B)  等價於  (not A) or  (not B)
not (A or  B)  等價於  (not A) and (not B)
```

例如「不是（成年**且**有票）」等價於「未成年 **或** 沒票」。觀念題常給你一個條件式，問哪個選項跟它等價。

---

## 連鎖比較與 `in`

```python
score = 85
print(60 <= score < 90)      # True  Python 可以連著寫，等同 60<=score and score<90

print(3 in [1, 2, 3])        # True   成員判斷
print('a' in "apple")        # True
print(5 not in [1, 2, 3])    # True
```

---

## 哪些值會被當成假？

放進 `if` 判斷時，下列值視為 `False`，其餘皆為 `True`：

```
False, 0, 0.0, ""（空字串）, []（空串列）, {}（空字典）, None
```

```python
if []:
    print("有東西")
else:
    print("空的")   # 輸出這行
```

## 五分鐘小練習

```quiz
Q: `print(True or False and False)` 會輸出什麼？
* True
- False
- 會噴錯
- None
E: and 的優先順序比 or 高，所以先算 False and False = False，再算 True or False = True。

Q: 依笛摩根定律，`not (A or B)` 等價於下列何者？
* `(not A) and (not B)`
- `(not A) or (not B)`
- `A and B`
- `not A or B`
E: ¬(A∨B) = ¬A∧¬B。口訣：把 not 分進去，and 與 or 要互換。

Q: `x = 0` 時，`if x != 0 and 10 / x > 1:` 為什麼不會發生除以零的錯誤？
* 因為短路求值：and 左邊已是 False，右邊不會被執行
- 因為 Python 允許除以零
- 因為 10 / 0 會回傳 0
- 其實會噴錯
E: and 只要左邊為假就直接得出 False，右邊整段跳過不執行。所以「先檢查再使用」的順序很重要，寫反了就會出錯。

Q: 下列哪個值放進 if 判斷時會被當成 False？
* `[]`（空串列）
- `[0]`
- `"0"`
- `-1`
E: 空串列、空字串、0、0.0、{}、None 都視為 False。注意 [0] 與 "0" 都「有東西」，所以是 True。
```

## 常見錯誤

- **`=` 打成 `==`**：在 `if` 裡寫 `if x = 5:` 會直接語法錯誤。
- **把 `and` / `or` 的優先順序記反**：`not` > `and` > `or`，不確定就加括號。
- **忘了 `True` / `False` 首字大寫**：Python 不是 `true` / `false`。
- **短路求值的順序寫反**：檢查條件（如 `x != 0`、`i < len(a)`）一定要放在使用它的那一邊之前。
