# 05 位元運算

位元運算直接對整數的二進位表示法**逐位操作**。這是官方明列的初級檢測範圍，但很多人會漏掉，考出來就送分給別人了。

---

## 先看懂二進位

```python
print(bin(13))         # 0b1101   十進位轉二進位（前面的 0b 是標記）
print(int('1101', 2))  # 13       二進位字串轉十進位

# 13 = 8 + 4 + 0 + 1 = 1101
#      2³  2²  2¹  2⁰
```

---

## 五個位元運算子

| 運算子 | 名稱 | 規則 |
|---|---|---|
| `&` | AND | 兩位都是 1 才得 1 |
| `\|` | OR | 任一位是 1 就得 1 |
| `^` | XOR | 兩位**不同**才得 1 |
| `~` | NOT | 每一位反轉（結果為 `-x-1`） |
| `<<` `>>` | 左移／右移 | 整體往左／往右移動幾位 |

```python
a = 12   # 1100
b = 10   # 1010

print(a & b)   # 8   1100 & 1010 = 1000
print(a | b)   # 14  1100 | 1010 = 1110
print(a ^ b)   # 6   1100 ^ 1010 = 0110
print(~a)      # -13 （反轉後等於 -a-1）
```

### 手算的方法：對齊後逐位比對

```
   1100   (12)
&  1010   (10)
-------
   1000   = 8

   1100   (12)
|  1010   (10)
-------
   1110   = 14

   1100   (12)
^  1010   (10)     ← 只有「上下不同」的位才是 1
-------
   0110   = 6
```

## 位移運算

左移 n 位等於**乘以 2 的 n 次方**，右移 n 位等於**除以 2 的 n 次方後無條件捨去**。這是考題最愛的簡化技巧。

```python
print(5 << 1)   # 10   101 → 1010   相當於 5 × 2
print(5 << 3)   # 40   相當於 5 × 2³ = 5 × 8
print(20 >> 1)  # 10   10100 → 1010  相當於 20 // 2
print(20 >> 2)  # 5    相當於 20 // 4
print(7 >> 1)   # 3    111 → 11，小數部分被丟掉
```

## 四個必考的實用技巧

```python
# 1. 判斷奇偶（比 % 2 更快）
n = 7
print(n & 1)        # 1 代表奇數，0 代表偶數

# 2. 判斷是否為 2 的次方
n = 16
print(n > 0 and (n & (n - 1)) == 0)   # True
# 原理：16 是 10000，15 是 01111，相 AND 得 0

# 3. 不用暫存變數交換兩數
a, b = 5, 9
a = a ^ b
b = a ^ b
a = a ^ b
print(a, b)   # 9 5

# 4. 取出最低位的 1
n = 12          # 1100
print(n & -n)   # 4   （1100 的最低位 1 在第 3 位，值為 4）
```

> **XOR 的三個重要性質**：`x ^ x = 0`、`x ^ 0 = x`、以及滿足交換律。所以一堆數字中「只有一個出現奇數次、其餘都出現偶數次」時，把全部 XOR 起來，剩下的就是那個落單的數字。這是經典考題。

```python
# 找出唯一只出現一次的數字
nums = [4, 1, 2, 1, 2]
result = 0
for x in nums:
    result ^= x
print(result)   # 4
```

## 用位元當「開關」

```python
flags = 0b0000

flags |= 0b0100    # 打開第 3 個開關
print(bin(flags))  # 0b100

print(bool(flags & 0b0100))   # True   檢查第 3 個開關是否開著

flags &= ~0b0100   # 關掉第 3 個開關
print(bin(flags))  # 0b0

flags ^= 0b0010    # 切換第 2 個開關（開變關、關變開）
print(bin(flags))  # 0b10
```

## 五分鐘小練習

```quiz
Q: `12 ^ 10` 的結果是多少？（12 是 1100、10 是 1010）
* 6
- 8
- 14
- 2
E: XOR 只有「上下不同」的位才是 1：1100 ^ 1010 = 0110 = 6。AND 得 8、OR 得 14，別記混了。

Q: `5 << 3` 等於下列哪個運算？
* 5 × 2³
- 5 × 3
- 5 ÷ 2³
- 5 + 3
E: 左移 n 位等於乘以 2 的 n 次方，所以 5 << 3 = 5 × 8 = 40。右移則是除以 2 的 n 次方並無條件捨去。

Q: 要用位元運算判斷整數 n 是不是偶數，下列哪個寫法正確？
* `(n & 1) == 0`
- `n & 1 == 0`
- `n & 2 == 0`
- `n | 1 == 0`
E: n & 1 取出最低位元，是 0 就是偶數。但位元運算的優先順序比比較運算「低」，不加括號的 n & 1 == 0 會被解讀成 n & (1 == 0)，所以括號一定要寫。

Q: 一串數字中只有一個數出現奇數次、其餘都出現偶數次，把「全部數字 XOR 起來」會得到什麼？
* 那個出現奇數次的數字
- 0
- 所有數字的總和
- 最大的數字
E: 因為 x ^ x = 0、x ^ 0 = x，成對的會互相抵銷掉，最後只剩落單的那個。這是經典考題。
```

## 常見錯誤

- **把 `^` 當成次方**：Python 的次方是 `**`，`^` 是 XOR。這是從別的語言轉過來最常犯的錯。
- **`&` 跟 `and` 混用**：`&` 是位元運算（對數字的每個 bit），`and` 是邏輯運算（對真假值）。
- **忘記運算優先順序**：位元運算的優先順序**比比較運算低**，所以 `n & 1 == 0` 其實會被解讀成 `n & (1 == 0)`；保險起見寫成 `(n & 1) == 0`。
- **`~` 的結果算錯**：`~a` 等於 `-a-1`，不是單純把 0/1 對調後的正數。
