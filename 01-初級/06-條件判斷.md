# 06 條件判斷

Python 用**縮排**（通常 4 個空白）表示程式區塊，不用大括號。縮排錯了會直接語法錯誤或邏輯跑掉，這是初學者最常出錯的地方。

---

## if / elif / else

```python
score = 76
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "D"
print(grade)   # C
```

> **`elif` 是「由上往下、符合就停」**：條件式會依序檢查，一旦某個條件成立就執行對應區塊、其餘全部跳過。所以**條件順序很重要**，寫錯順序（例如把範圍寫反）是觀念題常考的抓錯題。

如果把上面的順序反過來寫成 `if score >= 70: ... elif score >= 80: ...`，那 95 分的人會在第一個條件就被判成 "C"，後面的分支永遠輪不到。

## 巢狀條件與邏輯運算子合併寫法

```python
age = 20
has_ticket = True

# 巢狀寫法
if age >= 18:
    if has_ticket:
        print("可以入場")
    else:
        print("沒有票")
else:
    print("未成年")

# 用 and 合併，等價但更簡潔
if age >= 18 and has_ticket:
    print("可以入場")
```

## 三元運算式（一行寫完 if-else）

```python
n = 5
result = "偶數" if n % 2 == 0 else "奇數"
print(result)   # 奇數
```

## 短路求值

`and` / `or` 只要能提前判斷結果就不會算後面。例如 `x != 0 and 10 / x > 1`，當 `x` 為 0 時左邊已是 `False`，右邊的除法根本不會執行，不會發生除以零的錯誤。

- A
- B
- 什麼都不印
E: elif 是「由上往下、符合就停」。95 在第一個條件 s>=70 就成立了，印出 C 後面全部跳過。分段判斷一定要「從最嚴格的條件開始寫」。

* 縮排
- 大括號 {}
- begin / end
- 分號 ;
E: Python 靠縮排（通常 4 個空白）決定區塊範圍，縮排不一致會直接 IndentationError。

Q: `result = "偶數" if n % 2 == 0 else "奇數"`，當 n = 7 時 result 是？
* 奇數
- 偶數
- True
- 會噴錯
E: 三元運算式的讀法是「條件成立取前面的值，否則取 else 後面的值」。7 % 2 是 1 不等於 0，所以取 "奇數"。

## 常見錯誤

- **縮排混用 Tab 與空白**：看起來一樣但 Python 會噴 `TabError`，整份程式只用空白（4 格）最安全。
- **忘記冒號**：`if x > 0` 少了結尾的 `:` 會語法錯誤。
- **分段條件順序寫反**：判斷等第、判斷級距時，一定要從最大（最嚴格）的條件開始往下寫。
- **`elif` 寫成連續的 `if`**：連續 `if` 是「每個都檢查一遍」，可能同時成立執行多次；`elif` 才是「擇一」。
