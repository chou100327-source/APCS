# 07 迴圈

迴圈是 APCS 觀念題「**追蹤程式執行結果**」考最多的主題，一定要能手動模擬每一輪迴圈變數怎麼變化。

---

## `range()` 的三種用法

```python
for i in range(5):         # 0,1,2,3,4
    print(i, end=" ")
print()

for i in range(2, 6):      # 2,3,4,5
    print(i, end=" ")
print()

for i in range(10, 0, -2): # 10,8,6,4,2 （負的 step，倒數）
    print(i, end=" ")
```

重點：`range(a, b)` 是**含頭不含尾**，會跑 `b - a` 次。

---

## `while` 迴圈

```python
n = 1
total = 0
while n <= 100:
    total += n
    n += 1
print(total)   # 5050
```

---

## `break` / `continue`

```python
for i in range(1, 20):
    if i % 7 == 0:
        break          # 遇到第一個 7 的倍數就整個跳出迴圈
    if i % 2 == 0:
        continue       # 遇到偶數，跳過本次剩下的程式，直接進下一輪
    print(i, end=" ")
# 輸出：1 3 5
```

## 巢狀迴圈（雙迴圈）

```python
# 印出九九乘法表的一部分
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}*{j}={i*j}", end="  ")
    print()  # 內層跑完換行

# 輸出：
# 1*1=1  1*2=2  1*3=3
# 2*1=2  2*2=4  2*3=6
# 3*1=3  3*2=6  3*3=9
```

雙迴圈的總執行次數 = 外層次數 × 內層次數，這是**時間複雜度** O(n²) 的由來（見單元 18）。

## `for...else` 與 `while...else`

Python 特有語法，迴圈「**正常跑完（沒有被 break）**」才會執行 `else` 區塊，常用來做「有沒有找到」的判斷，例如線性搜尋。

```python
target = 99
nums = [3, 5, 7, 9]
for x in nums:
    if x == target:
        print("找到了")
        break
else:
    print("沒找到")   # 因為迴圈正常跑完沒 break，會執行這行
```

## 五分鐘小練習

```quiz
Q: `for i in range(2, 6)` 這個迴圈會跑幾次？
* 4 次
- 5 次
- 6 次
- 3 次
E: range(a, b) 含頭不含尾，會跑 b - a 次，也就是 i = 2,3,4,5 共 4 次。

Q: 下面這段會印出什麼？`for i in range(1, 6):` / `  if i % 2 == 0: continue` / `  print(i, end="")`
* 135
- 246
- 12345
- 1
E: continue 是「跳過本輪剩下的程式，直接進下一輪」，所以偶數都被跳過，只印出奇數 1、3、5。break 才是整個跳出迴圈。

Q: for...else 的 else 區塊在什麼時候會執行？
* 迴圈正常跑完、中途沒有被 break 時
- 迴圈一次都沒跑時
- 迴圈被 break 中斷時
- 每一輪迴圈結束時
E: 這是 Python 特有語法，常拿來做「找遍了都沒找到」的處理；只要中途 break 過，else 就不會執行。

Q: `for i in range(3):` 裡面再放 `for j in range(4):`，內層的 print 總共會執行幾次？
* 12 次
- 7 次
- 4 次
- 3 次
E: 3 × 4 = 12 次。雙層迴圈的總次數是相乘，這也是 O(n²) 複雜度的由來。
```

## 常見錯誤

- **`range` 的邊界少一或多一**：要跑 1~n 是 `range(1, n + 1)`，不是 `range(1, n)`。這是 off-by-one 最常見的來源。
- **`while` 忘了更新變數**：`while n <= 100:` 裡忘了寫 `n += 1` 就會無窮迴圈。
- **在迴圈裡改動正在走訪的 list**：邊走訪邊 `remove()` 會跳過元素，要改成走訪副本或改用新 list 收結果。
- **內外層迴圈變數用同一個名字**：外層用 `i`、內層也用 `i` 會互相覆蓋，內層請改用 `j`。
