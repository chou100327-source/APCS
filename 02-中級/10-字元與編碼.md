# 10 字元與編碼

官方把「字元（character）」單獨列為中級檢測範圍。Python 沒有獨立的字元型別，**單一字元就是長度為 1 的字串**，但編碼轉換的觀念一定要會。

---

## `ord()` 與 `chr()`：字元與編碼互轉

```python
print(ord('A'))    # 65    字元 → 編碼
print(ord('a'))    # 97
print(ord('0'))    # 48
print(chr(65))     # A     編碼 → 字元
print(chr(97))     # a
```

### 一定要記住的三組起點

| 字元範圍 | 起始編碼 | 結束編碼 |
|---|---|---|
| `'0'` ～ `'9'` | 48 | 57 |
| `'A'` ～ `'Z'` | 65 | 90 |
| `'a'` ～ `'z'` | 97 | 122 |

只要記住 `'A'` 是 65、`'a'` 是 97，其餘都能推算。大小寫相差 **32**，也就是 `ord('a') - ord('A') == 32`，這個數字考題常用。

---

## 字元的相對位置

```python
# 'D' 是第幾個字母？（A 算第 0 個）
print(ord('D') - ord('A'))    # 3

# 第 5 個字母是什麼？
print(chr(ord('A') + 5))      # F

# 數字字元轉成真正的數字
c = '7'
print(ord(c) - ord('0'))      # 7
print(int(c))                 # 7  （更直覺的做法）
```

---

## 大小寫轉換

```python
c = 'k'
print(chr(ord(c) - 32))    # K   小寫轉大寫
print(c.upper())           # K   內建方法（實際考試用這個就好）

c = 'M'
print(chr(ord(c) + 32))    # m
print(c.lower())           # m
```

## 字元的判斷方法

| 方法 | 判斷什麼 | 範例 |
|---|---|---|
| `.isdigit()` | 是數字字元嗎 | `'7'.isdigit()` → `True` |
| `.isalpha()` | 是英文字母嗎 | `'a'.isalpha()` → `True` |
| `.isalnum()` | 是字母或數字嗎 | `'a1'.isalnum()` → `True` |
| `.isupper()` | 是大寫嗎 | `'A'.isupper()` → `True` |
| `.islower()` | 是小寫嗎 | `'a'.islower()` → `True` |
| `.isspace()` | 是空白字元嗎 | `' '.isspace()` → `True` |

## 字元也可以比大小

比較的其實是**編碼值**，所以大寫字母全部小於小寫字母。

```python
print('a' < 'b')            # True   97 < 98
print('Z' < 'a')            # True   90 < 97
print('apple' < 'banana')   # True   字串從第一個字元開始逐一比較
```

## 典型考題：凱撒加密

把每個字母往後移 n 位，超過 Z 要繞回 A。用 `% 26` 處理繞回是關鍵。

```python
def caesar(text, shift):
    result = ""
    for ch in text:
        if ch.isupper():
            result += chr((ord(ch) - ord('A') + shift) % 26 + ord('A'))
        elif ch.islower():
            result += chr((ord(ch) - ord('a') + shift) % 26 + ord('a'))
        else:
            result += ch      # 非字母原樣保留
    return result

print(caesar("Hello, APCS!", 3))   # Khoor, DSFV!
print(caesar("Khoor", -3))         # Hello
```

公式讀法：**先減掉起點變成 0~25 → 位移 → `% 26` 繞回 → 再加回起點**。Python 的 `%` 對負數會回傳正值，所以往前移（負的 shift）也能直接套用同一條公式。

## 統計字母出現次數

```python
text = "programming"
count = [0] * 26                    # 26 個字母的計數器

for ch in text:
    if ch.isalpha():
        count[ord(ch.lower()) - ord('a')] += 1

for i in range(26):
    if count[i] > 0:
        print(chr(ord('a') + i), count[i])
```

## 五分鐘小練習

```quiz
Q: `ord('a') - ord('A')` 等於多少？
* 32
- 26
- 65
- 0
E: 'a' 是 97、'A' 是 65，相差 32。所以 chr(ord(c) - 32) 可以把小寫轉大寫（不過實務上用 .upper() 就好）。

Q: 把數字字元 '7' 轉成整數 7，下列哪個做法「不正確」？
* `ord('7')`
- `int('7')`
- `ord('7') - ord('0')`
- `ord('7') - 48`
E: ord('7') 得到的是編碼值 55，不是 7。要減掉 ord('0')（48）才會變成真正的數字。

Q: 凱撒加密裡為什麼要 `% 26`？
* 讓超過 Z 的字母繞回 A
- 讓字母變成大寫
- 因為英文有 26 個字母所以要除以 26
- 為了加快運算
E: 先把字母轉成 0~25 的編號，位移後可能超過 25（或變負數），用 % 26 就能繞回字母表範圍內，再加回起點編碼。

Q: `print('Z' < 'a')` 的結果是？
* True
- False
- 會噴錯
- 不一定
E: 字元比大小其實是比編碼值：'Z' 是 90、'a' 是 97，所以 90 < 97 成立。所有大寫字母都小於所有小寫字母。
```

---

## 常見錯誤

- **`ord()` 回傳值直接當數字用**：`ord('7')` 是 55 不是 7。
- **忘了非字母要原樣保留**：凱撒加密題常含空白與標點，別把它們也拿去位移。
- **`% 26` 的位置寫錯**：必須「減起點 → 位移 → `% 26` → 加回起點」，順序錯了結果就不對。
- **大小寫沒分開處理**：大寫用 `ord('A')` 當起點、小寫用 `ord('a')`，混用會跑出奇怪字元。
