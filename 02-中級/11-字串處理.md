# 11 字串處理

字串在 Python 裡也可以用索引、切片，但字串是「**不可變（immutable）**」的，不能直接改某個字元。

---

## 索引與切片

```python
s = "APCS2026"
print(s[0])       # A
print(s[-1])      # 6
print(s[0:4])     # APCS
print(len(s))     # 8
print(s[::-1])    # 6202SCPA   （反轉字串常用寫法）

# s[0] = 'X'      # ❌ 錯誤！字串不能單獨改某個字元
```

要「修改」字串，實務做法是先轉成 list 改完再 `join` 回來，或用切片重新拼接。

---

## 常用字串方法

| 方法 | 用途 | 範例 |
|---|---|---|
| `.upper()` / `.lower()` | 轉大寫／小寫 | `"abc".upper()` → `"ABC"` |
| `.strip()` | 去除頭尾空白（含換行） | `" hi \n".strip()` → `"hi"` |
| `.split(sep)` | 依分隔字元切成 list | `"a,b,c".split(",")` → `['a','b','c']` |
| `"sep".join(list)` | list 合併成字串 | `"-".join(['a','b'])` → `"a-b"` |
| `.replace(a,b)` | 取代子字串 | `"aabb".replace("a","x")` → `"xxbb"` |
| `.find(x)` | 找子字串位置，找不到回傳 -1 | `"hello".find("l")` → `2` |
| `.count(x)` | 計算子字串出現次數 | `"aabaa".count("a")` → `4` |
| `.isdigit()` | 是否全為數字字元 | `"123".isdigit()` → `True` |

## 字串與編碼

```python
print(ord('A'))            # 65   （字元轉碼值）
print(chr(65))             # A    （碼值轉字元）
print(chr(ord('a') + 1))   # b    常用來做「字母往後移一位」

# 判斷回文（順著讀和反著讀一樣）
def is_palindrome(s):
    return s == s[::-1]

print(is_palindrome("racecar"))   # True
print(is_palindrome("apcs"))      # False
```

---

## 遍歷字串裡的每個字元

```python
s = "Hello"
count_upper = 0
for ch in s:
    if ch.isupper():
        count_upper += 1
print(count_upper)   # 1
```

## 五分鐘小練習

```quiz
Q: `s = "APCS"` 之後執行 `s[0] = 'X'` 會怎樣？
* 噴錯，字串不可變
- s 變成 "XPCS"
- s 不變但不噴錯
- s 變成 "X"
E: 字串是 immutable，不能單獨改某個字元。要改請轉成 list 改完再 "".join()，或用切片拼接。

Q: 判斷字串 s 是不是回文，最簡潔的寫法是？
* `s == s[::-1]`
- `s == s.reverse()`
- `s == reversed(s)`
- `s.count(s) == 1`
E: s[::-1] 是反轉後的新字串，直接跟原字串比對即可。字串沒有 .reverse() 方法，reversed(s) 回傳的是迭代器不能直接比較。

Q: `"a,b,c".split(",")` 的結果是？
* ['a', 'b', 'c']
- "abc"
- ['a,b,c']
- ('a', 'b', 'c')
E: split 依分隔字元切開，回傳 list。反向操作是 ",".join(['a','b','c']) 變回 "a,b,c"。

Q: `"hello".find("z")` 回傳什麼？
* -1
- 0
- None
- 噴錯
E: find 找不到時回傳 -1（不會噴錯）。index() 才是找不到就噴 ValueError。
```

## 常見錯誤

- **想直接改字串某個字元**：字串不可變，一定要重建。
- **`.strip()` 忘了寫**：用 `input()` 讀進來的資料在某些判題系統會帶換行或空白，比對字串時先 `.strip()` 比較保險。
- **`find()` 與 `index()` 混用**：找不到時 `find()` 回傳 -1、`index()` 會噴錯。
- **在迴圈裡用 `s += ch` 串接大量字元**：資料量大時會很慢，改成先收進 list 最後 `"".join(list)`。
