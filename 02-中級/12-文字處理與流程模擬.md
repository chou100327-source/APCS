# 12 文字處理與流程模擬

官方對中級題本的描述是「能進行**文字處理與流程模擬**」。這個單元把陣列、字元、字串三樣東西組合起來，練的是**解題套路**而不是單一語法。

---

## 套路一：逐字掃描並累積狀態

大多數文字處理題都能用「一個迴圈掃過去，途中維護幾個變數」解決。

```python
# 計算一段文字有幾個單字（用空白分隔）
text = "the quick brown fox"
print(len(text.split()))    # 4

# 不用 split，自己掃描（考題可能限制用法）
count = 0
in_word = False
for ch in text:
    if ch != ' ' and not in_word:
        count += 1
        in_word = True
    elif ch == ' ':
        in_word = False
print(count)   # 4
```

## 套路二：用陣列（或字典）當計數器

```python
# 找出出現最多次的字母
text = "mississippi"
count = {}
for ch in text:
    count[ch] = count.get(ch, 0) + 1

best = max(count, key=count.get)
print(best, count[best])   # i 4

# 找出第一個不重複的字元
for ch in text:
    if count[ch] == 1:
        print(ch)   # m
        break
```

## 套路三：雙指標（頭尾往中間夾）

```python
# 判斷回文，但要忽略非字母與大小寫
def is_palindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True

print(is_palindrome("A man, a plan, a canal: Panama"))   # True
```

## 套路四：流程模擬（照題目指令一步步做）

這類題目不需要聰明的演算法，只要**嚴格照著規則執行**，難的是把規則翻譯成程式碼、還有處理邊界。

```python
# 模擬：一排座位，依序安排客人，客人會選最靠左的空位
seats = ['.'] * 10
guests = [3, 2, 4]      # 每組人數

for g in guests:
    placed = False
    for i in range(len(seats) - g + 1):
        # 檢查 i 開始的 g 個位子是否都空著
        if all(seats[i + k] == '.' for k in range(g)):
            for k in range(g):
                seats[i + k] = str(g)
            placed = True
            break
    if not placed:
        print(f"{g} 人組坐不下")

print(''.join(seats))   # 333224444.
```

## 套路五：字串的組裝與拆解

```python
# 把句子中每個單字反轉，但單字順序不變
s = "hello world apcs"
print(' '.join(w[::-1] for w in s.split()))   # olleh dlrow scpa

# 壓縮連續重複字元：aaabbc → a3b2c1
s = "aaabbc"
result = ""
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j] == s[i]:
        j += 1
    result += s[i] + str(j - i)
    i = j
print(result)   # a3b2c1
```

> **解實作題的固定流程**：先在紙上用範例資料手動跑一遍，確認自己真的懂規則；再想清楚要維護哪些變數；最後才寫程式。直接開始打字是最容易卡住的做法。

## 套路六：邊界條件檢查清單

寫完程式送出前，用這張清單自我檢查，可以救回很多分數：

```
□ 輸入只有 1 筆資料時會怎樣？
□ 輸入是空字串或 0 時會怎樣？
□ 陣列索引會不會超出範圍（第一個和最後一個）？
□ 所有元素都一樣時？全部遞增或全部遞減時？
□ 輸出格式對嗎（要不要換行、空白、小數位數）？
□ 迴圈的邊界是 range(n) 還是 range(n+1)？
```

## 五分鐘小練習

```quiz
Q: 要統計每個字元出現幾次，用字典時 `count[ch] = count.get(ch, 0) + 1` 裡的 `get(ch, 0)` 是什麼意思？
* 取 ch 的值，若 ch 還不存在就當成 0
- 把 ch 設成 0
- 刪除 ch
- 回傳字典大小
E: .get(key, 預設值) 可避免第一次遇到某字元時因為 key 不存在而噴 KeyError，是計數器的標準寫法。

Q: 雙指標判斷回文時，迴圈條件為什麼是 `while left < right` 而不是 `<=`？
* 兩個指標相遇（或交錯）就代表全部比完了
- 因為 <= 會噴錯
- 因為字串長度一定是偶數
- 沒有差別
E: 指標相遇時是同一個字元，跟自己比一定相等，沒必要再比一次；奇數長度的字串中間那個字元也是同理。

Q: 遇到「照題目規則一步步做」的流程模擬題，最好的第一步是？
* 先在紙上用範例資料手動跑一遍，確認規則理解正確
- 直接開始寫程式，邊寫邊想
- 先想有沒有更快的演算法
- 先寫輸出格式
E: 流程模擬題不考演算法技巧，考的是「有沒有正確理解規則」。手動跑一遍範例最能抓出誤解，也順便知道要維護哪些變數。
```

## 常見錯誤

- **一次想太多**：流程模擬題把規則拆成「每一步要做什麼」，一步一步寫，不要想一行解決。
- **邊界沒測**：只有 1 筆資料、空輸入、全部相同這三種情況最容易出錯，寫完一定要試。
- **輸出多了提示文字或少了換行**：對照題目的範例輸出逐字檢查。
- **字串串接效率**：長字串在迴圈內一直 `+=` 會很慢，改用 list 收集再 `join`。
