# 13 函式

函式讓程式碼可以重複使用。APCS 觀念題常考「**這個變數是全域還是區域**」「**有沒有 return**」。

---

## 定義與呼叫

```python
def add(a, b):
    return a + b

def greet(name="朋友"):      # 預設參數
    print(f"哈囉，{name}！")

print(add(3, 4))     # 7
greet()              # 哈囉，朋友！
greet("小美")        # 哈囉，小美！

def stats(nums):
    # 一次回傳多個值（其實是回傳一個 tuple）
    return min(nums), max(nums), sum(nums) / len(nums)

lo, hi, avg = stats([3, 7, 2, 9])
print(lo, hi, avg)   # 2 9 5.25
```

## 區域變數 vs 全域變數

```python
x = 10   # 全域變數

def foo():
    x = 20   # 這是「區域」變數，只在 foo() 裡面有效
    print("函式內：", x)

foo()
print("函式外：", x)
# 函式內： 20
# 函式外： 10   （全域的 x 沒有被改到！）

def bar():
    global x
    x = 99   # 加了 global，這裡改的才是全域變數

bar()
print(x)   # 99
```

## 沒有 return 的函式

如果函式跑完沒有 `return`，呼叫端拿到的值會是 `None`，這是觀念題常見的「猜輸出」陷阱。

```python
def f(n):
    if n > 0:
        return "正數"
    # n <= 0 時沒有寫 return

print(f(-5))   # None
```

## 五分鐘小練習

```quiz
Q: 全域有 `x = 10`，函式裡寫 `x = 20` 但沒加 global，呼叫函式後函式外的 x 是多少？
* 10
- 20
- None
- 會噴錯
E: 函式內指派會建立同名的「區域變數」，跟外面的全域 x 是兩個不同的東西。要改到全域必須先寫 global x。

Q: 函式跑完沒有執行到任何 return，呼叫端會拿到什麼？
* None
- 0
- 空字串
- 會噴錯
E: Python 函式預設回傳 None。條件分支沒寫齊（例如只有 if 沒有 else）時最容易踩到這個坑。

Q: `def stats(nums): return min(nums), max(nums)` 回傳的其實是什麼型態？
* tuple
- list
- 兩個獨立的值
- dict
E: 逗號分隔的多個回傳值會被打包成 tuple，接收端可以用 lo, hi = stats(...) 一次拆開。
```

## 常見錯誤

- **忘了 `return`，只有 `print`**：函式內 `print` 出來的東西無法被外面拿去運算，需要值就要 `return`。
- **想改全域變數卻沒寫 `global`**：函式內的指派只會建立區域變數。
- **可變的預設參數**：`def f(a=[])` 這種寫法在多次呼叫間會共用同一個 list，是 Python 有名的坑，預設值請用 `None` 再在函式內建立。
- **參數順序寫反**：`add(b, a)` 對減法、除法會得到完全不同的答案。
