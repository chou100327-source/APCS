# 14 遞迴

遞迴就是**函式呼叫自己**。寫遞迴一定要有兩個要素：**終止條件（base case）**和**往終止條件前進的遞迴呼叫**，缺一不可，否則會無窮遞迴直到程式當掉（`RecursionError`）。

---

## 兩個經典例子

```python
def factorial(n):
    if n == 0:              # 終止條件
        return 1
    return n * factorial(n - 1)   # 遞迴呼叫，n 越呼叫越小

print(factorial(5))   # 120

# 費氏數列： 0, 1, 1, 2, 3, 5, 8, 13, ...
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

print(fib(6))   # 8
```

## 手動追蹤遞迴呼叫過程（觀念題常考）

```python
def f(n):
    print("進入 f(", n, ")")
    if n <= 1:
        return 1
    result = n * f(n - 1)
    print("離開 f(", n, ") 回傳", result)
    return result

f(3)
# 進入 f( 3 )
# 進入 f( 2 )
# 進入 f( 1 )
# 離開 f( 2 ) 回傳 2
# 離開 f( 3 ) 回傳 6
```

重點：**呼叫是一層一層往下（先進去的最後回來）**，這就是「呼叫堆疊」的行為，跟單元 15 的堆疊是同一回事。

---

## 費氏數列遞迴版效率很差

`fib(n)` 樸素遞迴會重複計算大量相同的子問題，時間複雜度是**指數等級 O(2ⁿ)**。改善方式是加上「記憶化」（用 dict 存已經算過的結果）或改寫成迴圈版本，這是複雜度單元會呼應的重點。

```python
# 記憶化遞迴
memo = {}
def fib_memo(n):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n - 1) + fib_memo(n - 2)
    return memo[n]
```

---

## 遞迴 vs 迴圈

任何遞迴都可以改寫成迴圈（用自己的堆疊模擬），迴圈通常比較省記憶體；但有些問題（例如樹狀結構、河內塔）用遞迴寫起來邏輯簡單很多。APCS 觀念題重點是**看得懂遞迴怎麼一層層展開、一層層收回**。

## 五分鐘小練習

```quiz
Q: 寫遞迴函式時，缺少「終止條件」會發生什麼事？
* 無窮遞迴，最後噴 RecursionError
- 回傳 None
- 自動變成迴圈
- 只跑一次就結束
E: 沒有 base case 就永遠不會停，呼叫堆疊愈疊愈高直到爆掉。終止條件與「每次讓規模變小」缺一不可。

Q: `def f(n): return 1 if n == 0 else n * f(n-1)`，`f(4)` 的值是？
* 24
- 10
- 16
- 4
E: 這是階乘：4×3×2×1 = 24。展開順序是 f(4)→f(3)→f(2)→f(1)→f(0) 回傳 1 後再一層層乘回去。

Q: 樸素遞迴版的費氏數列 fib(n) 時間複雜度是？
* O(2ⁿ)
- O(n)
- O(n²)
- O(log n)
E: 每次呼叫都會再分出兩個子呼叫，呼叫樹接近滿二元樹，所以是指數等級。加上記憶化（memoization）後可降到 O(n)。

Q: 記憶化（memoization）的做法是？
* 把算過的結果存起來，下次遇到同樣的輸入直接回傳
- 把遞迴改成迴圈
- 增加遞迴深度上限
- 把結果印出來
E: 用 dict 快取子問題答案，避免重算，是把指數複雜度降到線性最直接的手段。
```

## 常見錯誤

- **忘記寫終止條件**或**終止條件永遠碰不到**（例如 `n` 沒有變小）。
- **忘了 `return` 遞迴呼叫的結果**：寫成 `factorial(n-1)` 而沒有 `return`，函式會回傳 `None`。
- **memo 沒有真的被使用**：記憶化要在函式一開始就先查 memo，算完也要存回去。
- **遞迴深度過深**：Python 預設遞迴上限約 1000 層，資料量大時要改用迴圈。
