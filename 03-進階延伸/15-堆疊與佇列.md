# 15 堆疊與佇列

這兩個是最基礎的資料結構觀念，APCS 用 `list` 就能模擬，重點是理解「**進出順序**」。

---

## 堆疊 Stack — 後進先出 LIFO（Last In First Out）

想像一疊盤子，只能從最上面拿、從最上面放。

```python
stack = []
stack.append(1)   # push
stack.append(2)
stack.append(3)
print(stack)       # [1, 2, 3]

top = stack.pop()  # pop，拿走最後放進去的
print(top)         # 3
print(stack)       # [1, 2]
```

### 經典應用：括號匹配

遇到左括號就 push，遇到右括號就檢查堆疊頂端是否為對應的左括號，是的話 pop，最後**堆疊要剛好清空**才算合法。

```python
def is_valid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in "([{":
            stack.append(ch)
        elif ch in ")]}":
            if not stack or stack.pop() != pairs[ch]:
                return False
    return len(stack) == 0

print(is_valid("({[]})"))   # True
print(is_valid("(]"))       # False
```

## 佇列 Queue — 先進先出 FIFO（First In First Out）

想像排隊買飲料，先排的人先拿到。Python 用 list 的 `pop(0)` 也能模擬，但效率較差（O(n)），正式場合建議用 `collections.deque`。

```python
from collections import deque

queue = deque()
queue.append("A")   # 進佇列 enqueue
queue.append("B")
queue.append("C")
print(queue)        # deque(['A', 'B', 'C'])

first = queue.popleft()   # 出佇列 dequeue，拿走最早進去的
print(first)              # A
print(queue)              # deque(['B', 'C'])
```

## 兩者比較

| | 堆疊 Stack | 佇列 Queue |
|---|---|---|
| 順序 | 後進先出 LIFO | 先進先出 FIFO |
| 生活例子 | 疊盤子、瀏覽器上一頁 | 排隊、印表機工作佇列 |
| 常見應用 | 括號匹配、遞迴呼叫、回溯 | 逐層搜尋 BFS、工作排程 |
| Python 寫法 | `list` 的 `append` / `pop` | `deque` 的 `append` / `popleft` |

## 五分鐘小練習

```quiz
Q: 依序把 1、2、3 push 進堆疊後連續 pop 兩次，會依序拿到什麼？
* 3, 2
- 1, 2
- 2, 3
- 3, 1
E: 堆疊是後進先出（LIFO），最後放進去的 3 最先被拿走。

Q: 括號匹配用堆疊，字串掃完後要「合法」的條件是？
* 堆疊必須是空的
- 堆疊剛好剩一個元素
- 堆疊元素個數是偶數
- 不用檢查
E: 堆疊非空代表還有左括號沒被關掉，例如 "((("。所以掃完要檢查 len(stack) == 0。

Q: Python 要實作佇列（FIFO），效率最好的做法是？
* `collections.deque` 的 append / popleft
- list 的 append / pop(0)
- list 的 append / pop()
- 用 dict
E: list.pop(0) 每次都要把後面所有元素往前搬，是 O(n)；deque 的 popleft 是 O(1)。list 的 pop() 拿的是最後一個，那是堆疊不是佇列。

Q: 遞迴函式的呼叫與返回順序，跟哪一種資料結構的行為一樣？
* 堆疊（後進先出）
- 佇列（先進先出）
- 二元樹
- 雜湊表
E: 最後被呼叫的函式最先返回，就是 LIFO，所以叫做「呼叫堆疊（call stack）」。
```

## 常見錯誤

- **用 `pop()` 當 `popleft()`**：`list.pop()` 拿的是最後一個（堆疊行為），佇列要拿最前面。
- **pop 空堆疊**：`[].pop()` 會噴 `IndexError`，取出前一定要先確認 `if stack:`。
- **括號匹配漏檢查最後的堆疊**：只比對配對卻忘了收尾檢查，`"((("` 會被誤判成合法。
- **忘了 `from collections import deque`**。
