# 16 排序演算法

APCS 最常考的三種排序法：**氣泡排序、選擇排序、插入排序**。重點不是背程式碼，而是**看懂「每一輪之後陣列變成什麼樣子」**，這是觀念題最愛出的追蹤題型。

---

## 氣泡排序（Bubble Sort）— 相鄰兩個一直比較、交換

```python
def bubble_sort(a):
    n = len(a)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a

print(bubble_sort([5, 2, 9, 1, 5, 6]))
```

每一輪跑完，「**最大值**」會像泡泡一樣浮到**最後面**，所以外層跑 n-1 輪、內層每輪範圍縮小 1。時間複雜度平均與最差都是 O(n²)。

---

## 選擇排序（Selection Sort）— 每輪找最小值放到前面

```python
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        a[i], a[min_idx] = a[min_idx], a[i]
    return a
```

每一輪都在「還沒排好」的部分找最小值，跟前面交換。也是 O(n²)，但**交換次數比氣泡排序少**（每輪最多交換一次）。

## 插入排序（Insertion Sort）— 像整理撲克牌

```python
def insertion_sort(a):
    for i in range(1, len(a)):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key
    return a
```

把每個新元素「插入」到前面已排序好的部分中正確的位置，**資料接近排序好時效率很高**（最好情況 O(n)），最差 O(n²)。

---

## 三者比較

| 排序法 | 核心動作 | 平均複雜度 | 穩定性 |
|---|---|---|---|
| 氣泡排序 | 相鄰交換 | O(n²) | 穩定 |
| 選擇排序 | 每輪選最小值 | O(n²) | 不穩定 |
| 插入排序 | 插入到已排序區段 | O(n²) | 穩定 |

> **觀念題常給你一個「排到一半」的陣列**，問你「這是哪一種排序法排到第幾輪的結果」。訣竅是看陣列前段／後段是否已經定型：**選擇排序前段會先定型、氣泡排序後段會先定型**。

## 五分鐘小練習

```quiz
Q: 氣泡排序每跑完一輪，哪個元素一定會歸位？
* 目前還沒排好的部分裡的「最大值」，會浮到最後面
- 最小值會到最前面
- 中位數會到中間
- 不一定
E: 相鄰比較交換會把大的一路往後推，所以每輪結束後「後段」會先定型。選擇排序則相反，是前段先定型。

Q: 給你排到一半的陣列，怎麼快速判斷是氣泡還是選擇排序？
* 看是前段先定型（選擇）還是後段先定型（氣泡）
- 看陣列長度
- 看有沒有重複元素
- 看數字大小
E: 這是觀念題的標準解法。選擇排序每輪把最小值放到前面，前段會先變成最終答案；氣泡排序把最大值推到後面，後段先定型。

Q: 資料「幾乎已經排好」時，哪種排序法最快？
* 插入排序
- 氣泡排序
- 選擇排序
- 三者一樣快
E: 插入排序在近乎有序的資料上，內層 while 幾乎不用搬移，最好情況是 O(n)。選擇排序不管資料長怎樣都要掃完，固定 O(n²)。

Q: 下列哪一種排序法是「不穩定」的（相同鍵值的相對順序可能被改變）？
* 選擇排序
- 氣泡排序
- 插入排序
- 三者都穩定
E: 選擇排序在交換時可能把相同值的元素順序打亂，所以不穩定；氣泡與插入只在「嚴格大於」時才搬動，因此穩定。
```

## 常見錯誤

- **迴圈邊界寫錯**：氣泡排序內層是 `range(n - 1 - i)`，少減 `i` 會做白工、少減 1 會索引越界。
- **交換寫成三行卻忘了暫存**：Python 直接用 `a[j], a[j+1] = a[j+1], a[j]` 最安全。
- **插入排序把 `key` 忘了先存起來**：`key = a[i]` 一定要在搬移之前抓好，否則會被覆蓋。
- **把「穩定性」想成「速度」**：穩定性講的是相同鍵值的相對順序會不會被打亂，跟快慢無關。
