# 18 時間複雜度

時間複雜度描述「**輸入資料量變大時，執行時間怎麼跟著成長**」，不是精確的執行時間。APCS 觀念題常給一段程式碼問你複雜度是多少，訣竅是數「**巢狀迴圈跑幾層、每層跑幾次**」。

---

## 六個要記熟的等級

| 複雜度 | 唸法 | 典型例子 |
|---|---|---|
| O(1) | 常數時間 | 取陣列第一個元素、四則運算 |
| O(log n) | 對數時間 | 二分搜尋 |
| O(n) | 線性時間 | 單層迴圈掃過整個陣列、線性搜尋 |
| O(n log n) | — | 合併排序、快速排序（平均） |
| O(n²) | 平方時間 | 雙層迴圈、氣泡排序、選擇排序 |
| O(2ⁿ) | 指數時間 | 樸素遞迴費氏數列 |

成長速度由小到大：**O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)**

## 對照程式碼看

```python
# O(1) — 不受 n 影響
def get_first(a):
    return a[0]

# O(n) — 單層迴圈跑 n 次
def sum_all(a):
    total = 0
    for x in a:
        total += x
    return total

# O(n²) — 雙層迴圈，各跑 n 次，合計約 n*n 次
def has_duplicate(a):
    n = len(a)
    for i in range(n):
        for j in range(i + 1, n):
            if a[i] == a[j]:
                return True
    return False

# O(log n) — 每次範圍砍半
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target: return mid
        elif a[mid] < target: lo = mid + 1
        else: hi = mid - 1
    return -1
```

## 判斷小訣竅

看迴圈是「**加法**（每次加／減一個固定值）」還是「**乘除**（每次乘 2 或除 2）」：

- 前者通常是 **O(n)**
- 後者通常是 **O(log n)**

雙層迴圈如果內層範圍跟外層無關（都跑滿 n 次）就是 **O(n²)**；如果內層範圍隨外層縮小（像氣泡排序），總次數約為 n²/2，**仍歸類為 O(n²)**（常數係數在 Big-O 中會被忽略）。

> 觀念題另一種出法：給幾段程式碼，問「當 n 很大時，哪一段最快 / 最慢」，只要照上面的成長速度排序就好。

## 五分鐘小練習

```quiz
Q: 一個演算法的運算次數約為 3n² + 5n + 2，它的時間複雜度是？
* O(n²)
- O(3n²)
- O(n)
- O(n² + n)
E: Big-O 只看成長最快的項，並且忽略常數係數與低次項，所以是 O(n²)。

Q: 輸入規模 n 從 1000 變成 2000，O(n²) 演算法的執行時間大約變成幾倍？
* 4 倍
- 2 倍
- 8 倍
- 不變
E: 執行時間跟 n² 成正比，n 變 2 倍時間就變 2² = 4 倍。O(n) 才是變 2 倍。

Q: 迴圈寫成 `while n > 1: n = n // 2`，這個迴圈的複雜度是？
* O(log n)
- O(n)
- O(1)
- O(n²)
E: 每次把 n 砍半，跑的次數約是 log₂n。判斷訣竅：變數是「乘除」變化就是對數等級，「加減」才是線性。

Q: 下列複雜度由小到大排列，何者正確？
* O(1) < O(log n) < O(n) < O(n log n) < O(n²)
- O(1) < O(n) < O(log n) < O(n²) < O(n log n)
- O(log n) < O(1) < O(n) < O(n²) < O(n log n)
- O(n) < O(log n) < O(1) < O(n log n) < O(n²)
E: 常數最快，接著對數、線性、線性對數，平方最慢（不算指數的話）。這個順序一定要背熟。
```

## 常見錯誤

- **把係數也寫進 Big-O**：沒有 O(3n²) 這種寫法，常數會被忽略。
- **內層跟外層有關就以為不是 O(n²)**：`for j in range(i+1, n)` 總次數約 n²/2，仍是 O(n²)。
- **把「迴圈層數」直接當次方**：內層若只跑固定次數（例如 `range(4)`）那仍是 O(n) 不是 O(n²)。
- **忽略內建函式的成本**：`in`、`max()`、`sorted()` 放在迴圈裡也會有代價，`x in list` 是 O(n)、`sorted()` 是 O(n log n)。
