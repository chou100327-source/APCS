- 考試日期：**2026-11-01**
- 讀書計畫：2026/09/13 起共 **50 天**，每天約 30 分鐘
- 目標範圍：**初級 + 中級**題本；進階延伸行有餘力再讀

## 學習網站

六個分頁：首頁（50 天計畫儀表板、依週分成 W1–W8、倒數、進度環，今天那一列會標亮）、教材（含內嵌互動動畫與逐行走讀）、觀念題（隨機抽 15 題、選項打亂、錯題重練）、程式判題（**在瀏覽器裡直接跑 Python**）、動畫圖解、速查・筆記。

本機執行（需本地伺服器，因為要讀取上層的 `.md`）：

```bash
python3 -m http.server 8000
# 開 http://localhost:8000/website/
```

線上部署（Vercel）：直接匯入此 repo 即可，`vercel.json` 會把根目錄導向 `/website/`。

詳見 `website/README.md`。

## 判題怎麼運作

用 **Pyodide**（把 CPython 編成 WebAssembly）在你自己的瀏覽器裡執行 Python，程式碼**不會送到任何伺服器**。第一次使用要下載約 10MB 的執行環境（需要網路，之後瀏覽器會快取）；教材閱讀、讀書計畫、觀念題測驗則完全離線可用。

> App 內建瀏覽器可能不支援 WebAssembly，判題會失效；請改用 Safari 或 Chrome 開啟。

## 跨裝置同步（選用）

進度、錯題、筆記、判題編輯器的程式碼平常存在瀏覽器（`localStorage`，只在該裝置）。要讓它們**跨裝置自動同步**，只要在 Vercel 加一個免費 KV：

1. Vercel 專案 → **Storage** → **Create Database** → 選 **KV（Upstash for Redis）** → 建立後點 **Connect** 連到本專案（會自動注入 `KV_REST_API_URL`、`KV_REST_API_TOKEN` 環境變數）。
2. **Redeploy** 一次讓環境變數生效。

之後 `/api/sync.js`（Serverless Function）會用單一 key（`apcs:sync:v1`）存全部資料；每台裝置開站自動拉、變更自動推。合併規則：進度／錯題用**聯集**（不會弄丟），筆記以 id 合併、刪除留墓碑，程式碼與最後選的題目取**較新**者。金鑰只在伺服器端，不進前端。沒設定 KV 時網站照常運作，只是不上雲。

## 程式碼慣例

- 全部 Python 3，縮排一律 4 個空白。
- 讀輸入用 `int(input())` / `map(int, input().split())`；輸出**只印答案本身**，不印提示文字。
- 二維陣列一律 `[[0] * c for _ in range(r)]`，不用 `[[0]*c]*r`（三列會共用同一個 list）。
