# APCS 初級・中級 Python 學習站（使用說明）

一個純前端的學習網站，把這個專案的教材整合成六個分頁：

1. **首頁（儀表板）** — 距考試倒數、50 天讀書計畫（**依週分成 W1–W8**，每張卡片就是一週），**今天那一列會標亮並自動捲到畫面中央**，可勾選標記完成、看整體進度環。**每一天都點得進去**：讀單元的日子開教材、練習日開練習頁、實作題日直接到程式判題並選好那一題、測驗日到觀念題並選好範圍、考古題日另開 ZeroJudge；每列最右邊的小圖示標示會去哪。
2. **教材** — 18 個單元、實作題與考前檢查表，側邊欄依「初級／中級／進階延伸」分組。讀到適合的主題時會**自動在內文嵌入互動動畫**（二維陣列、方向陣列、字母頻率、遞迴、堆疊、佇列、排序、二分搜尋、複雜度）；程式碼區塊可按「**逐行走讀**」：每一行拆開講「在做什麼、每個部分的意思（例如 `range(1, 6)` 會直接算出 1～5 共 5 輪、凱撒公式拆成四步）、它屬於哪個迴圈或條件底下」，可以點程式碼任一行直接跳過去，或用鍵盤 ← → 切換。
3. **觀念題** — 70+ 題觀念選擇題，可依「初級／中級／進階延伸」篩選，**每次隨機抽 15 題並打亂選項順序**，交卷即時對答案＋詳解，答錯的自動進「錯題重練」。
4. **程式判題** — 貼上或上傳 Python 程式碼，**直接在瀏覽器裡執行**，自動比對多組測資，判定 AC / WA / RE / TLE。
5. **動畫圖解** — 10 組可逐步播放／自動播放的互動視覺化，集中在一頁隨時複習。
6. **速查・筆記** — 考前速查表（可一鍵複製程式碼）＋自己的筆記（可跨裝置同步）。

> 介面不使用 emoji，一律採用線條 icon；教材內文的裝飾性 emoji 也會在顯示時換成對應 icon（★☆ 難度、→ 箭頭等有意義的符號保留）。

## 怎麼開啟（重要）

網站要讀取上層資料夾的 `.md` 教材，瀏覽器不允許用 `file://` 直接開啟時讀本機檔案，所以要用一個**本地伺服器**打開。

在**專案根目錄**（也就是這個 `website/` 的上一層）開啟終端機，執行：

```bash
python3 -m http.server 8000
```

然後用瀏覽器打開：

```
http://localhost:8000/website/
```

> 若沒有 python3，用 Node 也可以：`npx serve` 或 `npx http-server`（再依它顯示的網址加上 `/website/`）。

## 判題怎麼跑的

判題用 **Pyodide**（把 CPython 編譯成 WebAssembly），Python **在你自己的瀏覽器裡執行**，程式碼不會送到任何伺服器。因此：

- **第一次按「執行」或「判題」要下載約 10MB 的執行環境**（需要網路），之後瀏覽器會快取，後續很快。
- 教材閱讀、讀書計畫、觀念題測驗、動畫圖解**都不需要網路**（除了字體與程式碼高亮的 CDN；離線時仍可讀，只是少了配色）。
- **App 內建瀏覽器**（例如從社群軟體點開）可能不支援 WebAssembly，判題會失效；請改用 Safari 或 Chrome。
- 為了避免無窮迴圈把分頁卡死，執行有行數上限，超過會判 **TLE**。
- `input()` 會從「自訂輸入」或該組測資逐行取值；讀超過資料筆數會提示 EOF。

## 想擴充內容？

- **加觀念題**：編輯 `quiz.js`，照現有格式加物件（`w` 範圍標籤：初級／中級／進階延伸、`q` 題目、`o` 選項、`a` 正解索引、`e` 詳解）。**正解一律寫在第一個選項**（`a:0`）沒關係，網站每次出題都會打亂選項順序。題目要放多行程式碼（追蹤題）時，`q` 用 `trace(程式碼字串, 問題文字)` 產生，會自動排版並跳脫 HTML 字元。
- **加判題題目**：編輯 `problems.js`，加 `{id, title, statement, tests:[{in,out}]}`。`out` 比對時會自動忽略行尾空白與結尾空行。**新增測資後一定要用參考解答實際跑過驗證**。
- **改讀書計畫 / 教材目錄**：編輯 `plan.js` 的 `STUDY`（`weeks` 定義每週的標題與日期範圍，`days` 是 50 天逐日內容，靠日期對應到週）。首頁的週卡片由它產生；教材側邊欄的單元清單在 `app.js` 的 `NAV_SECTIONS`。
- **把動畫掛到某篇教材**：在教材 `.md` 內文單獨一行寫 `[[viz:KEY]]`，或在 `plan.js` 的 `LESSON_VIZ` 加「教材路徑 → 動畫代號」；動畫本身寫在 `viz.js`。
- **完成度**存在瀏覽器 `localStorage`（鍵 `apcs.done`），並可透過 `/api/sync.js` 跨裝置同步。

## 檔案說明

| 檔案 | 作用 |
|---|---|
| `index.html` | 網站骨架與六個分頁 |
| `style.css` | 樣式（配色、儀表板、日程列、內嵌動畫、流程圖…） |
| `icons.js` | 線條 icon 集（`ICON(name, size)`，取代 emoji） |
| `plan.js` | 50 天讀書計畫資料 `STUDY`（週次＋逐日）＋倒數／本週計算＋教材對動畫的對照表 |
| `app.js` | 主邏輯：儀表板、閱讀器（含內嵌動畫、逐行走讀面板）、觀念題、Pyodide 判題、筆記、同步 |
| `explain.js` | 逐行走讀的說明產生器（把一行 Python 拆開解釋） |
| `viz.js` | 10 組互動視覺化與流程圖，對外提供 `window.VIZ` |
| `quiz.js` | 觀念題題庫 |
| `problems.js` | 判題題目與測資 |
| `cheat.js` | 考前速查表 |
| `sync.js` | 跨裝置同步的用戶端（後端在 `../api/sync.js`） |
