## 練習一：預測輸出（sep 與 end）

`print` 預設「用空白隔開、印完換行」。`sep` 改的是**中間**、`end` 改的是**結尾**。

```python
print("A", "B", "C")
print("A", "B", "C", sep="")
print("A", "B", "C", sep="-")
print(2026, 9, 14, sep="/")
print("Hello", end=" ")
print("APCS")
print("第一行", end="")
print("接在後面")
print(1, 2, 3, sep=", ", end="!\n")
```

**請寫下這 9 行 print 總共會印出幾行、每行長什麼樣子。**（提示：有 `end` 不是換行的那一行，下一個 print 會接在同一行。）

## 練習二：f-string 取小數位與補零

大括號 `{ }` 裡冒號 `:` 後面寫的是「格式」：
- `.2f` → 小數點後 2 位（會四捨五入）
- `03d` → 整數補零到 3 位
- `5d` → 整數佔 5 格寬（不夠的在左邊補空白）

```python
x = 3.14159
n = 7
name = "小明"
print(f"{x:.2f}")
print(f"{x:.0f}")
print(f"{n:03d}")
print(f"[{n:5d}]")
print(f"[{x:8.3f}]")
print(f"{name}考了{n * 10}分")
h, m = 9, 5
print(f"{h:02d}:{m:02d}")
```

**請寫下 7 行輸出。**（中括號是為了讓你看得出前面有幾個空白。）

## 練習四：找出藏起來的空白

下面四種寫法都想印出 `1 2 3 4 5`，但**其中一種結尾會多一個空白**。是哪一種？

```python
# 寫法 A
for i in range(1, 6):
    print(i, end=" ")
print()

# 寫法 B
print(*range(1, 6))

# 寫法 C
print(" ".join(str(i) for i in range(1, 6)))

# 寫法 D（這個印的是逗號版）
print(*range(1, 6), sep=",")
```

## 五分鐘小測驗

```quiz
Q: `print("A", "B", sep="")` 會印出什麼？
* AB
- A B
- A,B
- A-B
E: sep 決定「中間」放什麼，給空字串就是什麼都不放，A 和 B 直接黏在一起。

Q: `print("x", end="")` 之後再 `print("y")`，畫面上是？
* xy（同一行）
- x 和 y 各一行
- x y（中間空一格）
- 只印出 y
E: end="" 讓第一個 print 印完「不換行」，所以下一個 print 會接在同一行後面。

Q: `f"{5:03d}"` 的結果是？
* 005
- 5.000
- 500
- 3
E: 03d 是「整數、補零到 3 位」，5 不足 3 位就在前面補兩個 0。時間 09:05 這種格式就是用 02d。

Q: `f"{2.675:.2f}"` 會取幾位小數？
* 2 位
- 3 位
- 不取，原樣輸出
- 會噴錯
E: 冒號後面的 .2f 就是「小數點後 2 位」。考試常要求「四捨五入到小數第 N 位」，就用 .Nf。
```

---

## 今天的重點

- `sep` 管中間、`end` 管結尾；`end` 預設是換行 `\n`
- f-string：`{值:格式}`，`.2f` 取小數、`03d` 補零、`5d` 佔寬度
- 用迴圈 `end=" "` 印一排數字，**結尾會多一個空白**；`print(*清單)` 或 `" ".join(...)` 比較乾淨

## 練習一

```
A B C
ABC
A-B-C
2026/9/14
Hello APCS
第一行接在後面
1, 2, 3!
```

9 個 print 只印出 **7 行**：`print("Hello", end=" ")` 和 `print("第一行", end="")` 都沒換行，所以各自跟下一個 print 接在同一行。

## 練習二

```
3.14
3
007
[    7]
[   3.142]
小明考了70分
09:05
```

- `{x:.0f}`：取到小數 0 位 → `3`
- `[{n:5d}]`：7 佔 5 格寬，前面補 **4 個空白**
- `[{x:8.3f}]`：`3.142` 是 5 個字，佔 8 格 → 前面補 **3 個空白**
- `{n * 10}`：大括號裡可以放運算式，先算出 70 再放進字串

## 練習三

```python
data = input().split()
name = data[0]
a, b, c = int(data[1]), int(data[2]), int(data[3])
avg = (a + b + c) / 3
print(f"{name} 的平均是 {avg:.2f}")
```

(80 + 91 + 77) / 3 = 82.666…，`.2f` 四捨五入成 `82.67`。

## 練習四

**寫法 A** 結尾會多一個空白：每個數字後面都印了 `end=" "`，連最後的 5 後面也有，所以實際輸出是 `1 2 3 4 5 `（5 後面有空白）。

有些判題系統會因為這個多出來的空白判錯。寫法 B、C 只在「數字之間」放空白，比較安全。寫法 D 印出來是 `1,2,3,4,5`。
