## 先記住三條規則

| 規則 | 例子 |
|---|---|
| `int()` 對小數是**往 0 捨去**，不是四捨五入 | `int(7.9)` → `7`，`int(-7.9)` → `-7` |
| 字串 `+` 是**接起來**，字串 `*` 是**重複** | `"12" + "3"` → `"123"`，`"ab" * 2` → `"abab"` |
| `/` 的結果**一定是小數**；有小數參與的 `//` 也是小數 | `7 / 7` → `1.0`，`7 // 2.0` → `3.0` |

## 五分鐘小測驗

```quiz
Q: `print(int("12") + 3)` 會印出什麼？
* 15
- 123
- "15"
- 會噴錯
E: int("12") 先把字串轉成整數 12，再加 3 等於 15。如果沒轉型直接 "12" + "3" 才會得到字串 123。

Q: `print(str(3) * 3)` 會印出什麼？
* 333
- 9
- 3 3 3
- 會噴錯
E: str(3) 是字串 "3"，字串乘以 3 是「重複 3 次」得到 "333"。數字 3 * 3 才是 9。

Q: `bool("0")` 的值是？
* True
- False
- 0
- 會噴錯
E: 只有「空字串」才是 False。"0" 裡面有一個字元，所以是 True。bool(0)（數字 0）才是 False。

Q: 把字串 "3.5" 轉成整數 3，正確寫法是？
* `int(float("3.5"))`
- `int("3.5")`
- `round("3.5")`
- `float(int("3.5"))`
E: int() 不接受帶小數點的字串，要先用 float() 變成 3.5，再 int() 往 0 捨去成 3。
```

## 練習一

| 題 | 輸出 | 為什麼 |
|---|---|---|
| 1 | `7` | int() 往 0 捨去，不是四捨五入 |
| 2 | `-7` | 往 0 的方向捨去，所以是 -7 不是 -8 |
| 3 | `15` | 先轉成整數 12 再加 3 |
| 4 | `123` | 兩個都是字串，+ 是接起來 |
| 5 | `5.0` | 2.5 × 2 = 5.0，浮點數乘出來還是浮點數，會有 `.0` |
| 6 | `333` | 字串 "3" 重複 3 次 |
| 7 | `3` | 先 float 成 3.5，再 int 捨去成 3 |
| 8 | `<class 'float'>` | `/` 的結果一定是小數，就算整除也是 1.0 |
| 9 | `False True False` | 只有空字串是 False；"0" 有內容所以 True；數字 0 是 False |
| 10 | `2 4` | 銀行家捨入：.5 會捨到最近的**偶數**，2.5→2、3.5→4 |

## 練習二

**第一行 `int("3.5")` 會當掉**（`ValueError`）。`int()` 看到字串裡有小數點就不接受。第二行先用 `float()` 轉成 3.5 再 `int()`，就沒問題。

## 練習三

不一樣：

```
3
3.0
```

`7 // 2` 兩邊都是整數 → 結果是整數 `3`；`7 // 2.0` 有小數參與 → 結果是小數 `3.0`。

## 練習四

```python
x = float(input())
print(int(x), int(x + 0.5))
```

7.6 + 0.5 = 8.1，int 捨去成 8；7.4 + 0.5 = 7.9，int 捨去成 7。這招只適用正數。
