## 先記住兩張表

**笛摩根定律**：把 `not` 分進括號裡時，**每一項都要反過來，而且 `and` ↔ `or` 互換**。

```
not (A and B)  等價於  (not A) or  (not B)
not (A or  B)  等價於  (not A) and (not B)
```

比較符號反過來的對照：

| 原本 | 反過來 |
|---|---|
| `>` | `<=` |
| `<` | `>=` |
| `==` | `!=` |
| `>=` | `<` |

## 練習一：笛摩根改寫（3 題）

把下面每個條件改寫成**不含最外面那個 `not`** 的等價寫法。

```python
# 第 1 題
not (a > 0 and b > 0)

# 第 2 題
not (x == 1 or y == 1)

# 第 3 題
not (age >= 18 and has_ticket)
```

提示：第 1 題的 `a > 0` 反過來不是 `a < 0`，想想 a 剛好等於 0 的時候。

## 練習二：哪些值是「假」？

下面的程式對每個值判斷真假。請寫下 10 個值各會印「真」還是「假」。

```python
values = [0, 0.0, "", " ", "0", [], [0], None, -1, "False"]
for v in values:
    if v:
        print(repr(v), "真")
    else:
        print(repr(v), "假")
```

（`repr(v)` 只是讓字串印出來時帶引號，方便你看清楚。）

## 練習三：優先順序

`not` 最先算，再來 `and`，最後才 `or`。請寫下三行的結果：

```python
print(True or False and False)
print(not True or True)
print(not (True or True))
```

## 練習四：短路求值

```python
x = 0
print(x != 0 and 10 / x > 1)
print(x == 0 or 10 / x > 1)
```

這兩行 `x` 都是 0，裡面都有 `10 / x`（除以零），但程式**不會當掉**。
請寫下兩行的輸出，並說明為什麼不會當掉。

## 練習五：連鎖比較

```python
print(1 < 5 < 3)
```

Python 允許把比較連著寫。這行印出什麼？把它改寫成用 `and` 連接的樣子。

## 五分鐘小測驗

```quiz
Q: `not (a > 0 and b > 0)` 的等價寫法是？
* `a <= 0 or b <= 0`
- `a < 0 or b < 0`
- `a <= 0 and b <= 0`
- `a > 0 or b > 0`
E: 兩個規則要一起用：每一項反過來（> 變 <=），而且 and 要換成 or。寫成 < 0 會漏掉 a 剛好等於 0 的情況。

Q: 下列哪個值放進 if 會被當成「真」？
* `" "`（一個空白的字串）
- `""`
- `0`
- `[]`
E: 只要字串裡有東西就是真，連一個空白也算。空字串、數字 0、空串列、None 才是假。

Q: `print(not True or True)` 會印出什麼？
* True
- False
- None
- 會噴錯
E: not 優先：先算 not True = False，再算 False or True = True。如果想要先算 or，要寫成 not (True or True)，那才是 False。

Q: `x = 0` 時，`x == 0 or 10 / x > 1` 為什麼不會除以零？
* or 左邊已經是 True，右邊根本不會執行
- Python 允許除以零
- 10 / 0 會等於 0
- 其實會當掉
E: 短路求值：or 只要左邊為真，整個結果就一定是真，右邊直接跳過。and 則是左邊為假就跳過右邊。
```

# 解答

**先確定你已經自己寫過了。**

<br><br><br><br><br><br>

## 練習一

```python
# 第 1 題
a <= 0 or b <= 0

# 第 2 題
x != 1 and y != 1

# 第 3 題
age < 18 or not has_ticket
```

第 1 題最多人寫成 `a < 0 or b < 0`——但 a 剛好是 0 時原式 `not (0 > 0 and …)` 是 True，`a < 0` 卻是 False，兩者不等價。`>` 的相反是 `<=`。

（這三題的改寫我用程式把所有情況都跑過一遍，確定每一種輸入結果都相同。）

## 練習二

| 值 | 結果 | 說明 |
|---|---|---|
| `0` | 假 | 數字 0 |
| `0.0` | 假 | 小數 0 |
| `""` | 假 | 空字串 |
| `" "` | **真** | 有一個空白，不是空的 |
| `"0"` | **真** | 字串裡有字元 "0" |
| `[]` | 假 | 空串列 |
| `[0]` | **真** | 串列裡有一個元素 |
| `None` | 假 | 代表「沒有值」 |
| `-1` | **真** | 只有 0 是假，負數也是真 |
| `"False"` | **真** | 這是一個有 5 個字的字串，不是布林值 False |

口訣：**「空的」和「零」才是假**，其他都是真。

## 練習三

```
True
True
False
```

- 第 1 行：先算 `False and False` = False，再算 `True or False` = True
- 第 2 行：先算 `not True` = False，再算 `False or True` = True
- 第 3 行：括號先算 `True or True` = True，再 `not` 變 False

## 練習四

```
False
True
```

- 第 1 行：`and` 左邊 `x != 0` 是 False → 整個一定是 False，**右邊的 `10 / x` 沒有被執行**
- 第 2 行：`or` 左邊 `x == 0` 是 True → 整個一定是 True，**右邊也沒有被執行**

所以寫條件時，「先檢查再使用」的順序很重要：把 `x != 0` 放在 `10 / x` 前面。

## 練習五

```
False
```

`1 < 5 < 3` 等於 `1 < 5 and 5 < 3`。`1 < 5` 是 True，但 `5 < 3` 是 False，所以整個是 False。
