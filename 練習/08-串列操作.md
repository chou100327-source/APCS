## 先記住四個操作

| 寫法 | 做什麼 | 會回傳東西嗎 |
|---|---|---|
| `a.append(x)` | 把 x 加到**最後面** | 不會（回傳 None） |
| `a.insert(i, x)` | 把 x 插到**索引 i** 的位置，後面的往後擠 | 不會 |
| `a.remove(v)` | 移除**第一個值等於 v** 的元素（看「值」不是看位置） | 不會 |
| `a.pop()` / `a.pop(i)` | 拿走最後一個／索引 i 的元素 | **會**，回傳被拿走的那個 |

## 練習一：一步一步追蹤

```python
a = [3, 1, 4]
a.append(1)
a.insert(0, 9)
a.remove(1)
x = a.pop()
y = a.pop(0)
print(a, x, y)
```

請在紙上寫下**每一行執行完之後** `a` 的樣子，最後寫出 `print` 印什麼。

小提醒：`a.remove(1)` 的時候串列裡有兩個 1，會移除哪一個？

## 練習二：sorted() 和 .sort() 差在哪

```python
b = [5, 2, 8]
c = sorted(b)
print(b, c)

d = b.sort()
print(b, d)
```

兩個 `print` 各印出什麼？特別注意 `d` 是什麼。

## 練習三：切片練習

```python
a = [0, 10, 20, 30, 40, 50]
print(a[1:4])
print(a[:2])
print(a[-2:])
print(a[::2])
print(a[::-1])
```

## 五分鐘小測驗

```quiz
Q: `a = [1, 2, 1]` 執行 `a.remove(1)` 之後，a 是？
* [2, 1]
- [1, 2]
- [2]
- [1, 1]
E: remove 只移除「第一個」值為 1 的元素，後面那個 1 還在。要全部移除得用迴圈或串列推導式。

Q: `x = a.pop()` 之後 x 是什麼？
* 串列原本的最後一個元素
- None
- 串列原本的第一個元素
- 串列剩下的長度
E: pop 會「拿走並回傳」元素，不給索引就拿最後一個。append、insert、remove 則都不回傳東西（None）。

Q: `b = [3, 1, 2]` 之後 `d = b.sort()`，d 是？
* None
- [1, 2, 3]
- [3, 1, 2]
- 會噴錯
E: .sort() 是原地排序，會改到 b 本身，但回傳值是 None。想要一份排好的新串列請用 sorted(b)。

Q: `a = [0, 10, 20, 30, 40]`，`a[-2:]` 是？
* [30, 40]
- [40]
- [0, 10]
- [20, 30, 40]
E: -2 代表倒數第 2 個，冒號後面沒寫代表一路取到最後，所以是最後兩個。
```

# 解答

**先確定你已經自己寫過了。**

<br><br><br><br><br><br>

## 練習一

| 執行完這行 | a 的樣子 |
|---|---|
| `a = [3, 1, 4]` | `[3, 1, 4]` |
| `a.append(1)` | `[3, 1, 4, 1]` |
| `a.insert(0, 9)` | `[9, 3, 1, 4, 1]` |
| `a.remove(1)` | `[9, 3, 4, 1]` ← 移除的是**第一個** 1（索引 2 那個） |
| `x = a.pop()` | `[9, 3, 4]`，x = `1` |
| `y = a.pop(0)` | `[3, 4]`，y = `9` |

輸出：

```
[3, 4] 1 9
```

## 練習二

```
[5, 2, 8] [2, 5, 8]
[2, 5, 8] None
```

- `sorted(b)` 產生一份**新的**排好的串列給 c，b 本身沒變
- `b.sort()` 直接把 b 改成排好的，但它**回傳 None**，所以 d 是 None

考試常見錯誤寫法：`b = b.sort()`，這樣 b 會變成 None。

## 練習三

```
[10, 20, 30]
[0, 10]
[40, 50]
[0, 20, 40]
[50, 40, 30, 20, 10, 0]
[40, 30, 20]
```

最後一行：從索引 4（40）開始，每次 -1 往回走，走到索引 1 之前停下（不含 10），所以是 40、30、20。

## 練習四

```python
nums = list(map(int, input().split()))
print(max(nums), min(nums))
print(sorted(nums))
print(nums[::-1])
```

如果第二行寫成 `nums.sort()`，nums 會被改成排好的樣子，第三行倒過來就變成 `[9, 5, 2, 1]`，答案就錯了。
