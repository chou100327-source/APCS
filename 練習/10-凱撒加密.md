## 先把公式拆開看懂

把一個大寫字母 `ch` 往後移 `k` 位：

```python
chr((ord(ch) - ord('A') + k) % 26 + ord('A'))
```

由內往外讀，一共四步：

| 步驟 | 寫法 | 以 `ch = 'Y'`、`k = 3` 為例 |
|---|---|---|
| ① 變成 0~25 的編號 | `ord(ch) - ord('A')` | 89 − 65 = **24** |
| ② 往後移 k | `+ k` | 24 + 3 = **27** |
| ③ 超過 25 就繞回來 | `% 26` | 27 % 26 = **1** |
| ④ 變回字母 | `chr(… + ord('A'))` | chr(1 + 65) = chr(66) = **'B'** |

所以 Y 往後 3 位是 B（Y→Z→A→B）。**第 ③ 步就是 `% 26` 存在的原因**：沒有它，27 + 65 = 92 會變成 `\` 這種奇怪符號。

Q: 凱撒加密公式裡，`ord(ch) - ord('A')` 這一步的目的是？

- 把大寫變小寫

E: 先把 A~Z 對應成 0~25，位移後用 % 26 就能繞回範圍內，最後再加回 ord('A') 變回字母。

* 24
- -2
- 2
- 23

- cnt[3]
- cnt[99]
- cnt[67]
E: ord('c') - ord('a') = 99 - 97 = 2，所以是索引 2（a 是 0、b 是 1、c 是 2）。

## 練習一

```
3
Z
1
24
```

- `ord('D') - ord('A')` = 68 − 65 = 3（D 是第 3 個，A 算第 0 個）
- `chr(65 + 25)` = chr(90) = Z
- (24 + 3) % 26 = 27 % 26 = 1 → 對應 B
- (1 − 3) % 26 = −2 % 26 = **24** → 對應 **Y**（B→A→Z→Y）

## 練習二

```python
def caesar(text, k):
    result = ""
    for ch in text:
        if ch.islower():
            result += chr((ord(ch) - ord('a') + k) % 26 + ord('a'))
        else:
            result += ch
    return result
```

三個空格依序是 `ord('a')`、`26`、`ch`。
